# Research notes

Primary-source investigation captured while a decision was being made. One file
per question, dated, with every claim labelled by how it was established:
**verified** (executed here, output reproduced), **cited** (read from the linked
primary source), or **inferred** (reasoning from those facts, untested).

**Reasoning does not live here.** A note records what was found; why the
repository then did what it did is in [`docs/adr/`](../adr/). A note is never
edited to match a later decision — if it turns out to be wrong, it gains an
addendum saying so, because a research note that silently tracks the outcome is
no longer evidence that the question was open.

Notes arrive with the pull request that ratifies the decision they fed, so this
directory fills in as the record catches up with the work.
